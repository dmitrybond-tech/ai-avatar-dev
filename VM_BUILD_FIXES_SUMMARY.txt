================================================================================
KEY CHANGES EXPLAINED
================================================================================

DOCKER HARDENING (gateway + bot):
  1. BuildKit syntax (# syntax=docker/dockerfile:1.4)
     → Enables advanced features like RUN --network=host

  2. CA certificates installation
     → apt-get install -y ca-certificates
     → Fixes SSL verification issues on minimal base images

  3. Configurable PyPI index
     → ARG PIP_INDEX_URL=https://pypi.org/simple
     → Allows custom mirrors (Aliyun, Tsinghua, etc.)

  4. Retry logic and timeouts
     → --retries 5 --timeout 60
     → Handles transient network failures automatically

WEBSITE DOCKERFILE:
  - Before: corepack enable && corepack prepare pnpm@8.15.0 --activate
  - After:  npm i -g pnpm@8.15.0
  - Why:    Corepack makes network calls that fail on restrictive firewalls
  - Impact: Faster, more reliable, no DNS lookups

POST-RECEIVE HOOK:
  - Stage-0 only: Builds gateway + bot (not website)
  - Network-robust: Uses --network=host for all builds
  - Health checks: Verifies gateway is responding before exit
  - No-build restart: Uses pre-built images to avoid double-building

DIAGNOSTIC SCRIPT:
  - 5 checks: Host DNS, Docker DNS, PyPI reachability, daemon config, BuildKit
  - Color-coded output: ✅ PASS, ⚠️ WARN, ❌ FAIL
  - Actionable recommendations: Specific fix commands for each issue
  - Exit code: 0 (success) or 1 (failure) for CI/CD integration
