│ QUICK START                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1. SETUP CREDENTIALS
   • Get Telegram bot token from @BotFather
   • Create Notion integration and database
   • Copy and configure environment:
     
     cp env.miniapp.example infra/compose/.env.miniapp
     notepad infra/compose\.env.miniapp

2. START SERVICES
   
   .\scripts\miniapp-up.ps1

3. START FRONTEND (in another terminal)
   
   cd apps\website
   pnpm dev

4. TEST IN TELEGRAM
   • Open your bot
   • Send: /start
   • Tap "🤖 Open Assistant"
   • Ask a question!

5. STOP SERVICES
   
   .\scripts\miniapp-down.ps1

Common issues:
  • Gateway not starting → Check NOTION_SECRET and NOTION_DB in .env.miniapp
  • Bot not responding → Verify TELEGRAM_TOKEN is correct
  • Frontend can't connect → Set PUBLIC_GATEWAY_URL in apps/website/.env
  • WebApp button doesn't work → WEBAPP_URL must be publicly accessible
